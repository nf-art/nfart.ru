# Лендинг Натальи Федотовой

## Запуск
Откройте `index.html` двойным кликом или разместите папку на любом статическом хостинге: GitHub Pages, Netlify, Vercel, Timeweb, Tilda Zero Block через вставку кода и т. п.

## Медиафайлы
Изображения подключены через публичные миниатюры Google Drive. Видеокейсы используют VK Video, Google Drive Preview и нативный HTML5-плеер для публичного файла Яндекс Диска. Для корректной работы у каждого исходного файла должен быть включён доступ «Все, у кого есть ссылка».

## Файлы
- `index.html` — структура страницы;
- `styles.css` — дизайн и адаптивность;
- `script.js` — анимации появления, шапка, лёгкий параллакс и получение актуальной ссылки на видео из публичного API Яндекс Диска.
